# go-toon

Go library for [TOON](https://toonformat.dev/) — a compact encoding of JSON aimed at LLM prompts.

This repo is built in public: the `blog/` folder walks through each step of the implementation.

```bash
go get github.com/abhishektakale/go-toon/toon
```

## status

Work in progress. See [blog/README.md](blog/README.md) for the build log.
